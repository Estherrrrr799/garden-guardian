# 🌿 Garden Guardian｜花园守护者
### 一场双人协作的 WebAR 解谜冒险

一场魔法风暴摧毁了精灵村庄。两位守护者需要沿着不同的路线探索花园，寻找隐藏的线索，携手重建精灵的家园。

**Garden Guardian** 是一款基于手机浏览器的 AR 游戏原型，将花园探索、角色解谜与面对面协作结合在一起。

👉 **[打开游戏原型](https://estherrrrr799.github.io/garden-guardian/)**

## ✨ 游戏介绍

两名玩家分别使用自己的手机，扮演不同角色，沿各自的路线寻找线索。

- **玩家 A｜侦探：** 从松树出发，解读线索，前往左侧长椅。
- **玩家 B｜侦察员：** 调查枯树桩，追踪风暴留下的痕迹，前往右侧长椅。

每名玩家都掌握着部分信息，需要通过交流与推理，将线索拼成完整答案，共同完成冒险。

## 🎮 玩法流程

以下为原型的预期体验流程：

1. **选择角色**  
   两名玩家分别在手机上打开游戏，选择玩家 A 和玩家 B。

2. **扫描与探索**  
   寻找指定的图像标记，通过手机摄像头扫描，触发 AR 元素、故事提示与谜题。

3. **交换线索**  
   沿各自的路线完成探索，向伙伴描述自己看到的线索，共同解开星座谜题。

4. **重建村庄**  
   在草坪中央会合，回顾探索过程中发现的符文，合作完成最终的排序挑战。

精灵伙伴会在旅途中提供提示与反馈。游戏设有能量星机制，答错会扣除能量星并触发倒计时惩罚。

## 📱 体验准备

完整体验需要：

- 两名玩家，每人一部带摄像头的智能手机。
- 网络连接，以及支持摄像头访问的手机浏览器。
- 与游戏匹配的图像识别标记和纸质星座参考卡。

**本项目采用图像追踪 AR。** 仅打开网址无法完成全部流程，还需要配套的识别图与游戏材料。

玩家通过面对面交流协作，并分别在自己的设备上推进游戏。

## 💡 设计思路

Garden Guardian 探索如何通过 AR，让玩家同时与真实空间和伙伴产生互动。

- **角色分工：** 不同的探索路线赋予每位玩家独立的任务与责任。
- **协作解谜：** 将信息分配给两名玩家，鼓励描述、倾听与共同推理。
- **环境叙事：** 将树木、长椅和草坪融入故事，让花园成为冒险的一部分。
- **探索引导：** 通过精灵提示、进度显示与视觉反馈，帮助玩家理解当前任务。

## 🛠 技术实现

- **HTML、CSS、JavaScript：** 游戏界面、谜题交互与流程逻辑。
- **MindAR：** 图像目标识别与追踪。
- **A-Frame：** AR 场景元素与动画。
- **GitHub Pages：** 网页托管与在线访问。

## 🚧 项目状态

本项目目前为交互原型，用于探索真实场景中的双人 WebAR 协作体验。

上述玩法描述了预期的游戏流程；移动设备兼容性与完整的实地体验仍需进一步验证。
